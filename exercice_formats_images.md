# Formats d'image : quel fichier pour quel usage ?

## 1. Deux grandes familles

# Exercice pratique : un fichier, cinq formats

**Durée : environ 45 min — Travail individuel ou en binôme**

## Objectif

Comprendre concrètement l'impact du choix de format sur le poids, la qualité et l'usage d'une image.

## Matériel

- Une photo fournie par l'enseignant (haute définition, ex. 4000 × 3000 px) OU une photo prise par l'élève
- Un logo simple fourni en vectoriel (SVG ou AI)
- Un logiciel d'export : Photoshop, Photopea (gratuit, en ligne), GIMP ou Affinity

## Partie 1 — La photo (20 min)

Exporter la même photo dans les formats suivants et compléter le tableau :

| Export | Poids du fichier | Qualité visuelle (zoom 100 %) | Adapté au web ? |
|---|---|---|---|
| JPEG qualité 100 % | | | |
| JPEG qualité 60 % | | | |
| JPEG qualité 10 % | | | |
| PNG | | | |
| WebP qualité 80 % | | | |

**Questions :**
1. Quel format donne le fichier le plus lourd ? Le plus léger ?
2. À partir de quel taux de compression JPEG les défauts deviennent-ils visibles ? Où apparaissent-ils en premier (aplats, contours, dégradés) ?
3. Pourquoi le PNG est-il un mauvais choix pour cette photo ?
4. Quel export choisiriez-vous pour un portfolio en ligne ? Justifiez (poids, qualité).

## Partie 2 — Le logo (15 min)

1. Exporter le logo en **PNG 200 × 200 px**, puis l'agrandir à 400 % dans un document. Que constate-t-on ?
2. Ouvrir la version **SVG** et l'agrandir de la même façon. Que constate-t-on ?
3. Ouvrir le fichier SVG avec un éditeur de texte (Bloc-notes). Que voit-on ? Qu'est-ce que cela nous apprend sur la nature du format ?

## Partie 3 — Cas pratiques (10 min)

Pour chaque situation, indiquer le format le plus adapté et justifier en une phrase :

1. Une affiche A3 à envoyer à l'imprimeur.
2. La photo d'un projet à publier sur un site portfolio.
3. Le logo de l'école à intégrer dans un site web.
4. Une capture d'écran d'interface à insérer dans un dossier de présentation.
5. Une image de produit avec fond transparent pour une boutique en ligne.
6. Le fichier de travail d'une retouche photo à reprendre le mois prochain.

## Pour aller plus loin (bonus)

- Tester le format **AVIF** (via Photopea ou squoosh.app) et comparer son poids au WebP.
- Sur squoosh.app, utiliser le comparateur avant/après pour visualiser précisément la perte de qualité.

## Critères de réussite

- Le tableau est complet et les poids relevés sont cohérents.
- L'élève sait expliquer la différence matriciel/vectoriel avec ses propres mots.
- Les choix de formats de la partie 3 sont justifiés par un critère pertinent (poids, qualité, transparence, destination écran/impression).
